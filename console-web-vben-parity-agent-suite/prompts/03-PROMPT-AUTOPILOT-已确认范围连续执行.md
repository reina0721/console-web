# 提示词 03：已明确范围连续执行

仅用于用户已经选择多个独立产品子项的情况。填入精确范围；待决策项不因连续模式获得默认答案。

```text
本次要求连续实施的范围仅为：<列出各 VP 子项、已明确需求与决策依据>。
先读取 tmp/、AGENTS.md、docs/README.md、docs/changes/115-vben-parity-calibration/ 的研究/需求/清单/设计协议、目标局部规则与主题 authority。
按依赖顺序依次处理上述范围；每项都先核对源码及消费者，按当前最新序号建立或恢复独立实施账本。保留认证、首页、八分类设置及既有 key/权限码兼容边界。
遇到未决子项跳过并记录原因；不以默认产品选择补齐、不创建占位功能。只继续无依赖且已要求的部分。
每批完成必要 codegen、公共能力扩展证据、局部检查和完整 pnpm check，记录实际结果；失败不能标完成，修复不得放宽门禁、预算或视觉阈值。最终报告完成/待决策/失败范围，不把文档校准完成等同产品完成。
```
