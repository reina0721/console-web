# 提示词 02：按已明确范围继续一个子项

使用前填入已经要求实施的具体子项；不要把“第一个未勾选”当产品范围授权。

```text
本次继续的已明确实施子项是：<VP-ID/子项及具体范围>。
请先读 tmp/、AGENTS.md、docs/README.md、docs/changes/115-vben-parity-calibration/ 的任务清单、对应需求和 design/execution-protocol.md，以及目标局部规则和主题 authority。
核对现有实现和所有消费者，优先恢复这一范围内真实进行中的变更账本；若尚无账本，按当前最新编号新建 docs/changes 账本。
仅实施上述子项，不自动认领整项 VP 或未决子项。遇到未解除的产品决策，报告具体问题，继续无依赖且已要求的部分。
完成相关生成与局部验证，再执行完整 pnpm check，记录实际退出码、证据与限制。只勾选实际完成并验收的内容；不修改认证自动降级边界或最近访问首页，不降低门禁，不自动更新视觉基线。
```
