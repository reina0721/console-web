## 当前保持的决策

- 认证只使用显式 mock/backend。Backend 网络、协议、401/403、超时及服务不可用保持各自错误语义，不切换模拟身份。
- 首页 `/` 维持“仅最近访问”。不添加虚构访问量、API 吞吐或错误率。
- 保留八分类设置、当前默认值、角色 ID、点分权限码、Store ownership、已有持久化 key 与数据迁移。
- 任务研究、需求、设计和验证只在 docs/changes 中维护。导入包仅提供导航和提示词，不复制另一套当前契约或状态机。
