- DataTable：UI Elements Data、Page Patterns、Page Archetypes resource-list、users 和 audit；部分经 data-display 聚合导出消费，不能只搜索单一 import 路径。
- detail-settings：settings/routes/layout、Page Pattern 和 Page Archetype Showcase；业务四分栏不能覆盖这些消费者的默认组合。
