## 明确不做（有依据，不是缩减范围）

- 滑块/点选验证：演示环境无安全价值，违反"客户端交互不冒充安全认证"。
- 页签拖拽排序：Surface authority 明确"保持访问顺序、不加拖拽重排"；以固定+操作菜单覆盖可发现性。
- 13 色板与任意 px 圆角：Design System 受控 accent 与 radius token 是产品视觉签名，任意值会破坏语义层。
- 虚拟滚动与表格内编辑：无真实业务数据规模与编辑路径需求，避免隐式写通道。
- 手机号/扫码/第三方登录、天气与头像插画：无对应后端或数据源，不伪造。

## 约束保持

- 认证：Backend 失败不返回 Mock 身份；演示能力只在 `NEXT_PUBLIC_AUTH_MODE=mock` 出现。
- 首页：`/` 仍为"仅最近访问"；Analytics/Workspace 是独立标准 Plugin 路由。
- 身份：角色 ID、点分权限码、账户隔离（`community-go.auth-owner`）、持久化 key 与历史数据兼容未变。
- Router：唯一真实 Router 仍为 Next App Router；插件 routes 由 codegen 生成。
- 菜单：部署期 Plugin Registry 只读；业务覆盖是独立 Host store + Port。
