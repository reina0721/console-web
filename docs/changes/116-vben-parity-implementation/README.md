## 实测方法（关键）

- Vben：Playwright（Chromium headless）+ 手动登录留存会话，逐页截图并抓取 `innerText`；
  覆盖登录、Analytics、Workspace、偏好抽屉五个分类、标签页、列设置/密度、权限演示、
  用户/角色/菜单/部门/字典、暗色主题。
- 本地：同一浏览器脚本对 `http://127.0.0.1:3000` 做同类场景截图与文本抓取，并复核
  加载/空/错误/只读/窄屏/暗色状态。
- 证据与限制见 [Vben 实测对照](research/vben-live-comparison.md)。

## 外部限制（未伪造）

1. Vben 演示站资源在 HTTP/2 下批量返回 503；`--disable-http2` 后正常加载。这不影响结构观察，
   但说明其边缘节点对连接复用敏感。
2. Vben 演示后端对用户/角色/字典等接口返回 503（页面显示"内部服务器错误"），
   因此这些页面的**数据态**只能观察空表 + 错误提示，不能据此断言其真实 CRUD 交互细节；
   本目录对这类能力只记录可见的结构、字段、工具栏与空/错态。
3. 未获取 Vben 源码；所有对标结论来自线上运行的 DOM/交互观察，不复制其源码、DOM、CSS 或资产。

## 与 115 校准结论的差异（已修订）

115 把多布局、页签固定、水印/锁屏、列设置下沉、树形行、系统模块、分析/工作台列为
"候选/待决策/暂缓"。本轮依据实际站点观察与项目架构评估，**逐项解除并实施**：

- 布局：Vben 提供 7 种布局；本项目在既有 Shell 模型内实现 3 种（侧边/顶部/混合）+
  现有密度/宽度/侧栏策略，等效覆盖其主路径；其余（双列菜单、内容全屏）无本项目对应
  信息架构，记录为等效替代而非缺失。
- 页签：Vben 有拖拽排序/中键关闭/最大数量等；本项目保持"访问顺序、不拖拽重排"的
  Surface authority，改用**显式单项操作菜单 + 固定页签 + 关闭左右/全部 + 中键关闭**
  覆盖其可发现性目标。
- 水印/锁屏：Vben 用插件水印与锁屏；本项目实现 Host 级水印覆盖层与客户端锁屏，
  并在 UI 中明确"不是安全边界"（Vben 未说明这一点）。
- 十色主题：Vben 13 色预设；本项目维持 4 个受控 accent（Design System authority），
  以语义 Token 一致性优先，记录为**等效替代**，不复制其色板。
- 表格：Vben 基于 vxe-table 提供固定列/树形/虚拟滚动/单元格编辑等；本项目在
  HeroUI Table 之上扩展固定列、树形行、列设置/密度/CSV，并以共享 Pattern 接入真实业务页。
  虚拟滚动、单元格/行内编辑不在本轮范围（无真实业务页需求），记录为未实现的具体项。

## 关键自主决策

见 [决策记录](design/decisions.md)。摘要：

1. 菜单业务覆盖由 **Host 持有持久化 + Port 暴露**，Plugin 只读部署期路由目录、写覆盖；
   Shell 与菜单管理页共用同一份数据（单一真相，非预览）。
2. 锁屏为**客户端锁定**，复用既有认证服务做密码复核，文案明确可绕过；不宣称安全策略。
3. 偏好新增第九分类而非塞进现有分类；旧记录按字段默认值补全，无需破坏性迁移。
4. 图表自建 SVG primitive（无图表依赖），支持主题/响应式/可访问摘要/键盘数据点。
5. 不做滑块验证：演示环境中的滑块不提供任何真实安全价值，按"客户端交互不冒充安全认证"排除。
6. 页面标签用可聚焦的操作菜单替代右键菜单（键盘/触摸可用性优先）。
