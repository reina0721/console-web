# Vben 线上演示实测对照

日期：2026-10-26（America/New_York）。对象：<https://www.vben.pro/>。
方法：Playwright Chromium（headless，1440×900，locale `zh-CN`），手动登录后保存
`storageState`，逐路由截图 + `document.body.innerText` + 关键 DOM（按钮/输入/表格/工具栏）。
本地同类场景用同一脚本对 `http://127.0.0.1:3000` 采集。

## 访问与证据限制

- HTTP/2 下 Vben 静态资源批量 503；`--disable-http2` 后全部 200。属其边缘节点问题，
  记录为环境限制，不影响结构观察。
- 登录后 `#/system/*`、`#/examples/vxe-table/basic` 等页面业务接口 503，表格多为
  "暂无数据" + "内部服务器错误" toast。**因此其真实数据态、分页/编辑交互未被观察**，
  本文件只陈述可见结构、字段、工具栏与空/错态。
- 未取得 Vben 源码；不复制其 DOM/CSS/资产。

## 一、登录与演示身份

**Vben 实际**：右侧登录卡：账号类型下拉（Super / Admin / User，切换即填入
`vben/123456`）、用户名、密码（显示/隐藏）、滑动验证条（"请按住滑块拖动"→"验证通过"）、
"记住账号"、忘记密码、登录、手机号登录/扫码登录两个替代入口、其他登录方式 4 个图标、
创建账号、ICP 备案信息；顶部有语言/主题/字号三个快捷控件。左侧品牌区含插画与标语。

**Console-web 本轮前**：邮箱+密码+登录/注册链接，Mock 与后端模式说明，错误横幅，
忘记密码/手机号/扫码均无；无角色快捷入口。

**差距处置**：实现三个真实角色身份快捷登录（管理员/操作员/受限成员，点击即真实登录
并进入对应权限体验）、"上次使用"记忆、演示数据重置（保留界面偏好）、模式与
"不构成安全认证"说明。**不实现滑块验证**（演示滑块无安全价值，见决策 D-05）；
手机号/扫码/第三方登录无对应后端能力，明确不伪造。Vben 有"记住账号"，本项目以
演示身份记忆等效（不记录密码）。

## 二、Shell、布局、页签、命令

**Vben 实际**

- 布局 7 种：垂直、双列菜单、水平、侧边导航、混合垂直、混合双列、内容全屏；内容
  流式/定宽；侧栏显示/拖拽/折叠/悬停展开/折叠显示菜单名/自动激活子菜单/宽度；顶栏
  显示/固定/菜单位置（左中右）；导航风格（圆润/朴素）/分离/手风琴；面包屑开关、
  仅一个隐藏、图标、首页按钮、风格；标签栏启用/持久化/访问历史/最大数量/拖拽排序/
  纵向滚轮/中键关闭/图标/更多按钮/最大化按钮/风格（谷歌/小部件）；顶部工具位可配置
  （全局搜索/偏好/主题/语言/时区/全屏/刷新/通知/锁屏/退出）；底栏与版权/ICP。
- 页签：分析页为固定页签（📌 图标、无关闭按钮）；其余页签带 X；标签条右侧有
  "全部关闭/刷新"控制与 `>>` 溢出菜单；多标签时横向滚动。
- 命令搜索：顶栏 `搜索 Ctrl K` 输入框（本环境 Ctrl+K 未观察为可用，输入框常驻）。
- 面包屑：分组 > 父级 > 当前页；另有平级/层级两种面包屑演示页。

**Console-web 本轮前**：仅侧边导航（可折叠）+ 顶栏（命令、语言、主题、通知、账户）；
页签默认关闭、可开关、可关闭/关闭其他/溢出选择；无面包屑渲染、无多布局、无锁屏/全屏/
刷新入口。

**差距处置**：新增 `layoutMode`（vertical/horizontal/mixed），顶部/混合布局复用同一
导航模型与权限过滤；页签增加固定（置顶、不可关闭、批量关闭保留）、单项操作菜单
（固定/关闭/关闭左右/全部/刷新）、中键关闭；面包屑沿用偏好开关（`breadcrumbs`）并
保持现有渲染；顶栏补齐快捷偏好与锁屏入口。**未实现**：拖拽重排（Surface authority
明确保持访问顺序）、最大化按钮、底栏/ICP、"双列菜单/内容全屏"（无对应产品 IA）。

## 三、偏好设置

**Vben 实际**（偏好抽屉五个分类，实时预览，右上角复制偏好设置、清空缓存并退出）：

- 外观：主题浅色/深色/跟随系统、深色侧边栏/子栏/顶栏、13 个内置色板 + 自定义、
  圆角滑杆 0–1、字体大小 px、色弱模式、灰色模式。
- 布局：见第二节的完整布局/内容/侧栏/顶栏/菜单/面包屑/标签栏/工具位/底栏配置。
- 快捷键：全局搜索 Ctrl K、退出 Alt Q、锁屏 Alt L、关闭当前窗口 Esc。
- 通用：语言、时区（America/New_York）、动态标题、水印、定时检查更新、显示复制按钮、
  页面切换进度条/Loading/动画。
- 拓展：插件注册的业务偏好分组（示例为看板标题/展示条数等）。

**Console-web 本轮前**：八分类设置页（外观/导航/数据展示/操作/语言地区/通知/可访问性/
快捷键）、恢复单类/全部、持久化失败提示、搜索目录与深链，无快捷抽屉、无 JSON 配置
输出、无水印/锁屏/色弱/灰阶。

**差距处置**：新增第九分类「安全与隐私」；快捷偏好抽屉复用同一 `PreferencesPort`
（单一 store/key/校验）；新增水印/空闲锁屏/后台锁定/色弱/灰阶；配置可复制/下载/导入
（整包校验，失败不部分应用）。**未实现**：圆角/字号 px 滑杆（项目已有 fontScale 三档与
受控 radius token，任意 px 会破坏 Token 体系）、13 色板（4 accent 为设计系统 authority）、
深色侧栏/顶栏独立开关（明暗由 Token 统一推导）、定时检查更新（无更新服务）。

## 四、高级表格与查询

**Vben 实际（可见结构）**

- 用户/角色/字典：左侧部门树（用户页）、查询表单（用户名/用户ID/性别/状态/备注/
  创建时间区间）+ 重置/搜索 + 收起；卡片头 `用户列表` + 新增 + 图标组（搜索折叠/
  刷新/全屏/列设置齿轮）；表格列头可排序；分页 `共 N 条记录` + `20 条/页` + 首/上/页码/下/尾。
- Vxe 表示例页：显示边框/显示 loading/显示斑马纹开关；树形表格、固定表头/列、
  自定义单元格、搜索表单、单元格编辑、行编辑、虚拟滚动、行标记。

**Console-web 本轮前**：DataTable（排序/选择/两档密度/固定表头/列宽拖拽）+ Collection
槽位；列设置/导出仅存在于 page-archetypes 私有实现；users 有查询与分页，audit 查询
较薄；无 CSV、无固定列、无树形行、无折叠高级筛选。

**差距处置**：把列设置/密度/CSV 导出/可见顺序提升为 Surface Foundation 共享组合
（`collection-tools`），DataTable 增加三档密度、固定列、树形行；CollectionQuery 支持
可折叠高级区与可移除筛选 chips；users/audit 真实接入（含列布局按用户/页面持久化、
CSV 含选中项导出、权限门控）；Showcase 同源演示。**未实现**：虚拟滚动（无 10k 级真实
数据页）、单元格/行内编辑（业务编辑走既有表单页，避免表格内隐式写路径）、斑马纹
（行分隔/密度已表达同一可读性目标）。

## 五、权限与系统管理

**Vben 实际**

- 前端权限演示：当前角色 super；三个"切换为 X 账号"按钮；组件/函数/指令三种控制方式，
  权限码 `AC_100100`（Super）与 `AC_100030`（Super & Admin），角色维度示例。
- 用户管理：部门树 + 查询 + 表格 + 列设置（后端 503，数据态不可观察）。
- 角色管理：查询（角色名称/角色ID/状态/备注/创建时间）+ 列表 + 修改/详情/删除 + 分页。
- 菜单管理：三级树表（标题/类型 菜单|目录/权限标识/路由地址/页面组件/操作），
  新增菜单、新增下级、修改、删除。
- 部门管理：树表（部门名称/状态/创建时间/备注/操作），新增部门/新增下级/修改/删除。
- 字典管理：查询（名称/编码/状态）+ 字典类型列表 + 新增类型（后端 503）。

**Console-web 本轮前**：点分权限码 + `useProductAccess` + 按钮级动作门控 + 角色权限编辑 +
只读权限页；无菜单/部门/字典。

**差距处置**：新增三个标准插件：menus（读部署期 catalog，维护标题/排序/可见性/权限码
覆盖，覆盖**真正作用于侧栏**）、departments（16 节点三级树、增删改、删除保护、乐观版本）、
dictionaries（5 类型 18 条目、编码唯一校验、条目 tone 仅语义值）。三者用唯一授权源
`useProductAccess('settings.update')`，拒绝态只读并给出原因；持久化损坏可恢复不覆盖。
**未实现**：Vben 的"指令方式"权限（React 无指令，组件/Hook 已覆盖同等能力）、
页面组件/物理文件编辑（部署期 Registry 只读，明确分离）。

## 六、Analytics 与 Workspace

**Vben 实际**

- 分析页：4 个 KPI 卡（用户量/访问量/下载量/使用量：当前值、图标、"总 X"总量），
  "流量趋势 / 月访问量"切换 + 面积折线图（0–80,000 轴、小时刻度），下方三卡
  （访问数量、访问来源 ×2）；顶部因后端 503 显示"内部服务器错误"toast。
- 工作台：问候卡（早安 + 天气，右侧 待办 2/10、项目 8、团队 300）、项目卡 6 项
  （图标/名称/寄语/分组/日期）、最新动态 7 条（头像/动作/相对时间）、快捷导航 6 项
  （首页/仪表盘/组件/系统管理/权限管理/图表）、待办事项 5 条（复选框/标题/描述/时间）。

**Console-web 本轮前**：首页仅最近访问；无分析、无工作台插件、无图表组件。

**差距处置**：新增 `/analytics`（4 KPI + 7/30/90 天面积趋势 + 来源环形 + 设备条形 +
页面排行 + 空/错/刷新真实状态 + 显式演示数据说明）与 `/workspace`（问候/统计/快捷导航
用真实 `route()` 目标/项目卡/动态/待办持久化）。图表为自建 SVG primitive：主题 token、
响应式 viewBox、`role="img"` + 隐藏数据表、数据点 roving tabindex 方向键导航、无动画。
**未实现**：Vben 的天气/头像插画（无数据源与资产，不伪造）、其 3 个来源图表的重复卡
（本项目用来源环形 + 设备条形 + 页面排行表达同一分析意图）。
