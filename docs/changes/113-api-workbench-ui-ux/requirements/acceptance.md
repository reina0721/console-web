# 验收要求

- 工作台容器 >=80rem 三栏，56–80rem 主从两栏，<56rem 使用请求/响应/Runner/任务视图及项目 Drawer。
- 同时只挂载一套编辑器；请求 ID、内存草稿与执行状态不因选择或容器变化丢失。
- 输入可读、按钮图文同轴、字段不重叠，正文不整页横向溢出；复用既有 Token、Element、Pattern、Motion。
- 保存成功必须来自持久化确认；失败保留草稿并允许重试。变量编辑使用明确提交，取消有未保存确认。
- 单次请求、Runner、任务手动运行共享执行链，分别表达 HTTP、断言和传输错误。
- 不存在调度实现时不展示调度中；仍允许保存配置与手动运行。
- 导入先校验并显示替换摘要；导出、复制、加载与格式化具有失败反馈。
- 保持 workspace v1 及原存储 key，不引入新的运行时依赖。
- 覆盖六档宽度、侧栏展开/收起、明暗与中英文、键盘/焦点、浮层打开态及 Axe AA，并运行 pnpm check。
