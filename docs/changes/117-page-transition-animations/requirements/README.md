# 需求与验收

## 用户需求

> 将当前项目页面切换动画保留默认使用，继续新增复刻 https://www.vben.pro/ 的多个页面切换动画，
> 在个人偏好里实现配置设置。

## 验收标准

| 编号 | 标准                                                                | 验收方式                                                                                      |
| ---- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| A1   | 默认值继续使用项目现行动画，视觉与交互不变                          | `page-transition.spec` 默认用例；既有 `transition.spec` 全通过；默认模式无 `surface-screen-*` |
| A2   | 提供 `fade` / `fade-slide` / `fade-up` / `fade-down` 四种 Vben 动画 | 每种一条 e2e，断言 `animation-name` 与 URL                                                    |
| A3   | 提供关闭选项，且只影响页面切换                                      | `none` 用例；`motion=reduced` 用例仍能整体降级                                                |
| A4   | 设置页与快捷偏好抽屉均可配置，同一状态                              | UI 用例 + 单元测试（同一 Port）；刷新后保持                                                   |
| A5   | 旧持久化记录不报错、自动落默认                                      | 单测「旧记录补 default」+ e2e「旧存储记录」                                                   |
| A6   | 减少动效 / Motion Screen off 时降级                                 | e2e 减少动效用例（时长 < 0.05s）                                                              |
| A7   | 不产生横向滚动或布局位移                                            | 390px `fade-slide` 用例 `scrollWidth <= innerWidth`                                           |
| A8   | 中英文、暗色、窄屏可用                                              | 设置页视觉基线 + 既有 `settings-product-review` 中英文扫描                                    |
| A9   | 文档、证据、任务状态与实现一致                                      | 本账本 + Motion Foundation + 质量证据                                                         |

## 非目标

- 不实现 Vben 的离场（leave）过渡：React commit 直接替换页面树，enter-only 为等效方案；
- 不实现 `fade-scale`（Vben 可选集合之外）；
- 不复制 Vben 源码、DOM、CSS 或资产；
- 不改变默认页面进入体验，不调整既有视觉基线（设置页新增字段除外）。
